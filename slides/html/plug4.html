The payoff. Each system team writes one MCP server; each agent vendor builds MCP support once. A new agent that speaks MCP can use all three servers with no new code, and a new system needs one server, not one connector per agent. At 5 agents and 20 systems: 25 pieces instead of 100. Say the caption out loud, because the picture can mislead. MCP is a protocol, an agreed message format like HTTP. It is not a product and not a server in the middle. The teal band is the shared language; at runtime Copilot connects directly to the claims MCP server. Today you see the teal box next to "Claims system" work; in the homework they write it. What MCP doesn't give you: permissions design, data validation or approval screens. Those stay your job, and the second demo shows why.
