"Copilot" here is the part on your laptop: Copilot Chat in VS Code, or the Copilot CLI in a terminal. In VS Code the MCP plumbing is VS Code's own; the CLI does it itself, and its wire log names it copilot-cli. Either way the request to your server starts on your machine. The model (GPT-6-Luna in our recorded runs) runs in GitHub's cloud: it only sees the tool list and the results. The jargon, if they ask: the local part is the host, which runs an MCP client for each server; your program is the MCP server. Hosts rename tools for the model: Codex shows get_claim as mcp__claims__get_claim, the Copilot CLI as claims-get_claim. Does the model run my code? No. The host starts your server on your machine (stdio) or calls it over the network (Streamable HTTP). The allow step happens under VS Code's default permission level, "Manual permissions".
