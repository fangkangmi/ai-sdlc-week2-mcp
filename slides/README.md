# Slides

To present, open `hand-roll-an-mcp-server.pptx`: 22 slides with speaker notes, exported from the deck
on 1 Oct 2026.

The deck itself is a claude.ai Slides artifact, and the rest of this folder is its source: `deck.json`
holds the title, slide order and sections; `html/<id>.html` is one slide each, with its speaker notes in
the `<aside>`. After changing the deck, export it again (Export → PowerPoint on the deck page) and
replace the `.pptx`.
