# Slides

The deck is a claude.ai Slides artifact (22 slides). This folder is its source: `deck.json` holds the
title, slide order and sections; `html/<id>.html` is one slide each, with its speaker notes in the
`<aside>`. The PowerPoint export (Export → PowerPoint on the deck page) goes here as
`hand-roll-an-mcp-server.pptx`.
